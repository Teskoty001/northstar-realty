# Northstar Realty – Real Estate Website

**Project Title:** Northstar Realty – Modern Real Estate Website

**My Role:** Front-End Web Developer

**Project Description:**

Designed and developed a modern, responsive real estate website for Northstar Realty using HTML, CSS and JavaScript.

The website features a clean and professional interface, property listings, interactive property filters, property details, responsive navigation and a contact section.

I also implemented WhatsApp integration, allowing potential clients to make property enquiries directly through WhatsApp with pre-filled messages.

The website is optimized for both desktop and mobile devices, providing a smooth and user-friendly browsing experience.

**Technologies Used:**
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages
